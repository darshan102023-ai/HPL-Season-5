
# HPL Season 5

**Hulithotlu Premier League Season 5**

Official tournament website for HPL Season 5 at Green Park Stadium, Hulithotlu.

## Project Features

- Responsive cricket tournament website
- Player and team registration
- Manual UPI payment verification
- Registration receipts by email
- Secure administrator login and dashboard
- Teams, fixtures, match results and points table
- Gallery, news and announcements
- Admin-controlled website branding and form settings

## Technology

- HTML
- CSS
- JavaScript
- Google Sheets
- Google Apps Script

## Project Structure

- `index.html` — Website structure
- `style.css` — Website design and responsive layout
- `script.js` — Frontend interactions and API helper
- `assets/` — Website images and other assets

## Backend

The Google Apps Script backend will be configured separately. API credentials and administrator passwords must never be committed to this repository.

## Venue

Green Park Stadium, Hulithotlu, Karnataka, India.
